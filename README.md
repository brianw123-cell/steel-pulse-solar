# Steel Pulse Solar

A browser game where you run a solar installation company. Start with one truck and a credit line, bid on jobs, install them, survive payroll, hire a crew, and try to grow without running out of cash.

**Play it:** https://steel-pulse-solar.vercel.app (installable as a phone app)

It's built to be fun, and to quietly teach how a contracting business really makes and loses money: cash flow timing, deposits, fixed overhead, the cost of finding customers, reputation, and scaling too fast. If a player walks away understanding that revenue isn't profit and profit isn't cash, the game did its job.

The full design, including every mechanic and the business lesson behind it, is in [GAME_SPEC.md](GAME_SPEC.md).

## Stack

A single HTML file with plain JavaScript and a service worker so it works offline. No build step.
